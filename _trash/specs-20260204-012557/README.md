# Specs

This folder contains product/engineering specs generated via the OpenClaw agent pipeline:

1) Product Strategist proposes/frames the feature
2) Backend Architect reviews feasibility, API/data model, risks
3) UI Implementation Specialist reviews frontend plan and UX/a11y considerations
4) Final consolidated spec is written to `specs/` and logged to Trello (list: `Features`) with the spec path

Template: `SPEC_TEMPLATE.md`
